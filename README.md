# Anantha Vijay — Cinematic Portfolio

React + Vite portfolio featuring GSAP, ScrollTrigger, Lenis smooth scrolling, magnetic buttons, cursor-following amber glow, section scrub transitions, an About bento layout, and a pinned horizontal project gallery on desktop (stacked cards on mobile).

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The CV and hero image are in `public/assets`. The horizontal project gallery is desktop-only; on narrow screens the project cards stack normally for usability. Reduced-motion preference is respected by the CSS animations.
